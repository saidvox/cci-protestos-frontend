# CCI Protestos Frontend

Frontend academico en React, Vite y TypeScript para representar el flujo de protestos, solicitudes, analistas y deudores.

## Ejecutar localmente

```bash
npm install
npm run dev
```

Variables utiles:

```text
VITE_API_URL=http://localhost:8080/api
VITE_USE_MOCKS=false
```

Comandos principales:

```bash
npm run build
npm run test
npm run lint
```

Las pantallas estaticas y mocks se conservan como referencia visual del flujo mientras el backend se termina de adaptar.
